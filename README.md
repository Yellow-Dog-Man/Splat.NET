# Splat.NET
This is a library to allow decoding a number of different gaussian splat formats using C# & .NET

It is based on this project: https://github.com/arloopa/UnitySplats

It has been "de-Unityfied" to allow use with any C#/.NET code outside of Unity and updated to modern .NET 10
